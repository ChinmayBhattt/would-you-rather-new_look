# 🎮 Would You Rather - Premium Game Experience

**A stunning and interactive twist on the classic “Would You Rather” game. Designed with smooth animations, gradient visuals, and real-time response feedback, this game offers a fun way to spark conversations or break the ice.**

## 🤩 Features

* ✨ Sleek gradient-based UI with glowing cards
* 📱 Fully responsive layout (mobile-first)
* 🔄 Dynamic question transitions

* 🧠 Smart screen switching and UX feedback
* 🎨 Modern typography with **Inter** and **Poppins**
